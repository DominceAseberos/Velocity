# VELOCE

## What is this?
VELOCE is a personal project built for practicing storytelling website development. It is designed around a premium, high-performance private car collection, focusing on cinematic video panels and immersive scrollytelling.

## Design System & Tech Stack
The project adheres to strict, high-end design standards featuring dark mode textures (carbon), gold accents, and elegant typography (Playfair Display & Mono) to deliver a luxury aesthetic.

- **Core**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, BEM CSS Architecture
- **Animations**: GSAP and Lenis for smooth scrolling, infinite marquees, and dynamic motion design.
